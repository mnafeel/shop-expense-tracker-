# Shop Expense Tracker

Track shop purchases and labour expenses. Data saves in your browser (localStorage).

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:5173/

## Deploy on GitHub Pages

1. Create a new repository on GitHub (e.g. `shop-expense-tracker`).
2. Push this project to the `main` branch:

```bash
git init
git add .
git commit -m "Initial commit: shop expense tracker"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPO.git
git push -u origin main
```

3. In the repo on GitHub: **Settings → Pages → Build and deployment → Source: GitHub Actions**.
4. After the workflow runs, your site will be at:

`https://YOUR_USERNAME.github.io/YOUR_REPO/`

Replace `YOUR_USERNAME` and `YOUR_REPO` with your GitHub username and repository name.
